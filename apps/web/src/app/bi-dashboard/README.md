# BI Analytics Dashboard

Demo de Business Intelligence integrada ao portfólio de Leonardo Santos Custódio.

## Objetivo

Simular um painel comercial executivo com experiência próxima de um produto real, sem depender de serviços pagos ou infraestrutura externa.

## Stack

- Next.js 16
- React 19
- TypeScript
- CSS responsivo usando o design system do portfólio
- Static Export compatível com Vercel e Cloudflare Pages

## Funcionalidades

- KPIs de faturamento, margem, pedidos, ticket médio e atingimento de meta
- comparação com período anterior
- filtros por período, região, canal e categoria
- gráfico temporal em SVG
- análise regional e por canal
- tabela de categorias
- insights automáticos
- exportação CSV dos dados filtrados
- layout responsivo para desktop e mobile
- dados demonstrativos determinísticos, sem custos de API ou banco

## Deploy

A rota é publicada junto do frontend do portfólio:

`/bi-dashboard/`

Isso mantém a demo 100% gratuita e sem dependências de backend.
